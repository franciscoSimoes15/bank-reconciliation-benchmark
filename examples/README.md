# Exemplos de execução

- `demo_success.md`: o M4 recupera corretamente um caso com ruído de referência.
- `demo_challenging.md`: um hard negative supera o candidato verdadeiro num cenário combinado. O erro é intencionalmente preservado para mostrar que o benchmark não foi desenhado para garantir sucesso.
- `demo_benchmark.jsonl`: oito casos, um por cenário, gerados com a development seed `7`.

Os dois relatórios mostram valores raw, valores normalizados, scores por campo e ranking dos 10 candidatos.
